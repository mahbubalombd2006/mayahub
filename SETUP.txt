MAYA HUB NEWS — ENGLISH VERSION

Files:
- index.html: English news homepage
- style.css: Responsive styling; top header stays fixed while scrolling
- app.js: Loads published news from Supabase
- SETUP.txt: This guide

Required changes:
1. Open app.js.
2. Replace YOUR_SUPABASE_PROJECT_URL with your Supabase Project URL.
3. Replace YOUR_SUPABASE_PUBLISHABLE_KEY with the Publishable Key from Supabase Dashboard > Project Settings > API Keys.
4. Never put a service_role or secret key in frontend code.
5. Your Supabase public.news table must have: id, title, content, image_path, status, created_at, published_at.
6. The Storage bucket name must be news-images.
7. This code uses signed URLs for a private bucket. Public visitors may need a storage.objects SELECT policy to create signed URLs. Apply policies carefully and only for the news-images bucket. If you want, we can set up this access in the next step.
8. Keep the existing admin-only INSERT/UPDATE/DELETE RLS policies on news and Storage.
9. Put all three code files in the root of your Vercel project and deploy.
10. This package contains the public homepage only. The admin page will be created separately.

The header is sticky at the top. There is no bottom navigation bar.
All visible homepage text and date formatting are in English.
