MAYA HUB NEWS ADMIN — SETUP

1. Open admin.js.
2. Replace YOUR_SUPABASE_PROJECT_URL with the Project URL from Supabase.
3. Replace YOUR_SUPABASE_PUBLISHABLE_KEY with the Publishable Key (starts with sb_publishable_).
4. Never use a service_role or secret key in browser code.
5. Create the admin user in Supabase Authentication > Users. The user's UUID must match the UUID in your admin-only RLS policies.
6. The public.news table must have: id, title, content, image_path, status, created_at, published_at.
7. Storage bucket must be named news-images.
8. Confirm admin-specific RLS policies allow this user to SELECT/INSERT/UPDATE/DELETE public.news rows.
9. Storage policies must allow this admin to INSERT and SELECT objects in news-images. Keep UPDATE/DELETE policies admin-only.
10. The homepage uses signed URLs for private images. Public visitors also need a carefully scoped Storage SELECT policy for the news-images bucket, or use a different image delivery approach.
11. Put admin.html, admin.css, admin.js in the same Vercel root folder as index.html, style.css, app.js.
12. Deploy, then open https://YOUR-SITE/admin.html.
13. The admin page uses Supabase Auth. Do not store passwords or secret keys in code.
